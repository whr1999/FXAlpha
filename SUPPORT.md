# Support

FXAlpha is currently an alpha, operator-managed research platform. Public issue
reports and design proposals are welcome, but no service-level agreement,
investment outcome, data entitlement, or production deployment support is
provided.

Before opening an issue:

1. reproduce the problem against a specific public commit and submodule pins;
2. remove credentials, production data, databases, artifacts, private logs, and
   identifying filesystem paths;
3. include the smallest reproducible command and sanitized output;
4. use a private GitHub security advisory rather than an issue for a suspected
   vulnerability.

Questions about Tushare access, Qlib internals, or QuantGPT upstream behavior
should be directed to the respective upstream project unless the problem is in
the FXAlpha integration layer.
